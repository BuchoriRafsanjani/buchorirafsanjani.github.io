Selected work

Internal tools I built at Dicoding. Each started as a problem I noticed, not an assignment.

Design request workflow

947 requests from 45 people across 8 teams in its first 135 days.

Problem
Design requests arrived as free-form Basecamp posts, each written differently. Requesters then had to mention an editor to get their brief reviewed.
What I built
A Google Form feeds an n8n workflow that logs each request, extracts the brief, has Claude review it, and creates a Basecamp card with the review attached.
Fixed along the way
Moved Basecamp access to per-user OAuth tokens and fixed API pagination issues.
Stack
n8n, Google Forms, Google Sheets, Google Docs, Claude, Basecamp API

Company policy chatbot

Used by 90+ employees to look up company policies, culture, and procedures.

Problem
Employees needed quick, reliable answers about company rules spread across policy documents.
What I built
A RAG chatbot that answers from the official policy documents, with an n8n workflow that collects the policy data.
Design choice
When a question isn’t covered by the documents, the chatbot says so and refers the employee to HR instead of guessing.
Stack
n8n, RAG, LLM API

Documentation

Alongside the tools, I write the documentation that keeps them usable: system documentation for the automation workflows I build, user guides for the colleagues who use them, and SOPs for internal editorial and operational processes.

As an editor, I hold documentation to the same standard as published content: accurate, consistent, and checked against its source. I work in Notion, Figma, Google Workspace, and GitHub.

How I build

I build with AI coding agents. I use Claude Code to write and change code, keep the work in Git, and test what the agent produces before anyone relies on it.

Eight years of writing and editing technical content taught me to check every claim against a source. I treat AI output the same way: it isn’t correct until I’ve verified it.

I run each tool as a small project: find the problem, gather requirements from the people affected, build, roll out, and keep improving it. I hold Google’s Foundations of Project Management certification.
